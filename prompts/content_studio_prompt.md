# AI Content Studio — Prompt Specification

## Purpose
Generate marketing and engagement content for yoga instructors, reducing the time spent on repetitive content creation while maintaining authenticity.

## Content types and specifications

### 1. Instagram Post
**Input:** Topic or theme, instructor name, optional key message
**Output:**
- Caption (80-150 words, conversational, with 3-5 relevant hashtags)
- Suggested image/visual direction (text description)
- Optimal posting time suggestion based on wellness audience patterns

### 2. Instagram Carousel Copy
**Input:** Topic, number of slides (4-8), key points to cover
**Output:**
- Slide-by-slide text (each slide: headline + 1-2 lines)
- Cover slide hook
- Final slide CTA

### 3. Reel/Short Video Script
**Input:** Topic, target duration (30s/60s/90s)
**Output:**
- Hook (first 3 seconds)
- Script with timing markers
- On-screen text suggestions
- CTA

### 4. Blog Post
**Input:** Topic, target length (500/800/1200 words), key points, SEO keyword
**Output:**
- Title (with SEO keyword)
- Meta description
- Full article with H2/H3 structure
- Internal link suggestions (to courses/programs)

### 5. Email Newsletter
**Input:** Theme, key announcement, instructor name
**Output:**
- Subject line (2-3 options)
- Preview text
- Body (200-300 words)
- CTA button text

### 6. WhatsApp Broadcast
**Input:** Purpose (class reminder, new program, wellness tip, seasonal greeting)
**Output:**
- Message (50-100 words, conversational, emoji-appropriate)
- CTA link text

### 7. Course/Program Description
**Input:** Course title, key features, target audience, duration, price
**Output:**
- Description (100-150 words)
- 3-5 benefit bullets
- Who-it-is-for statement
- What-you-will-learn list

### 8. SEO Metadata
**Input:** Page type (instructor profile, course, blog post), primary keyword
**Output:**
- Title tag (50-60 chars)
- Meta description (140-160 chars)
- 5-8 target keywords
- Schema markup suggestions

## Behavioral rules
- Match the instructor's voice and brand tone. The content should sound like the instructor wrote it, not like a generic AI.
- Never make medical or therapeutic claims.
- Hashtags should be relevant to yoga/wellness, not generic engagement bait.
- All content is a draft. The instructor reviews and approves before publishing.
- When generating for Yoga By Rachna Shah specifically, use the brand's established tone: warm, knowledgeable, community-oriented.

## Personalization layer
When the instructor's previous content is available in the knowledge base, the system should:
- Match their typical sentence length and complexity
- Use terminology they prefer (e.g., "practice" vs "workout", "students" vs "members")
- Reference their specializations naturally
- Avoid topics they have not previously covered without flagging it
